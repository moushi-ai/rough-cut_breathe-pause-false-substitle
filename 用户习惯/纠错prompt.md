# ASR 纠错规则

## 输入输出

输入：ASR 转录粗稿（每句一行）
输出：纠错后的文本（每句一行，与输入 1:1 对应，不做断行、不去标点）

## 核心前提

**输入对应一条剪好的成片视频**。逻辑一定通顺、顺序一定正确、严重口误已被剪掉。只保留自然的说话习惯（语气词、口头禅）。

**核心判断问：这句话在成片里，说话人真的会这么说吗？**
- 不会 → 是 ASR 错误，必须改
- 会，只是口头禅/语气词 → 保留

## 允许的四种操作

| 操作 | 场景 |
|---|---|
| 替换 | 同音字、谐音、英文误识别、拼音乱码 |
| 补漏字 | ASR 漏识别的单字 |
| 去重复 | ASR 叠字 |
| 保留 | 确实拿不准 → 保留原样，完成后列「不确定清单」给用户 |

## 必须保留

说话者的自然口头禅：呢、吧、就、直接、其实、然后、这个、那个、的话。这些是成片里正常存在的。

## 必须修正（ASR 错误信号）

- 逻辑不通、语义断裂
- 顺序混乱、语法错乱
- 明显重复（ASR 叠字）
- 单字+功能描述（多是英文词被 ASR 错译）
- 拼音乱码（英文被错转成拼音串）

## 专有名词与字幕保真

- 产品型号、品牌名：只在上下文已足以证明是 ASR 错听/错字时修正；不能把说话人使用的常见简称扩写成全称
- 模型名：不确定时**保留原 ASR 词**，不要瞎猜 Sonnet/Opus/Haiku
- 人名、机构、公司、地点、奖项、日期和数据等事实性内容：基础纠错阶段只做明显的 ASR 错字；不能用外部事实反向改写说话人实际说出的日期、数字、单位或观点。需要联网确认时，必须进入「事实核验」阶段；只有保持原话发音的 ASR 纠错才可生成候选，**未经人工确认不得替换**。

## 指代对象纠错

- 上下文唯一明确指向国家、市场、企业、机构等非人格主体时，使用「它」；上下文唯一明确指向实际人物时，按性别和原话使用「他 / 她」。
- 指代对象有歧义时，保留 ASR 原文并写入 `uncertain.md`；不得依赖常识或主观猜测替换。

## 正式成片字幕展示层（仅显式选择）

默认模式是 **ASR 保真**。只有用户明确选择「正式成片字幕」或同义展示风格时，才进入本节；不得根据“需要更好看”自行启用。

在正式成片字幕模式中，仍须保持原话内容和事实不变，但可进行以下展示规范化：

- 已确认术语统一为 `AI / IT / TCS` 等规范大写。
- 只规范**已纠错或已核验的事实型数值**：金额、数量、比例、年份、编号和明确时长等。可把对应的中文数值改为阿拉伯数字，保留原单位；四位及以上阿拉伯数字按千位分组，如 `2830 → 2,830`、`23460 → 23,460`。
- 不得机械数字化自然语言结构，例如「一边」「第一个」「一个人」「一套」；模糊数量、单位或数值有声学/事实不确定时，保持原样并列入不确定清单或走事实核验，不得猜测补全。
- 数字展示不得改变数值、单位、日期、比例或说话人观点。没有纠错/核验证据时，不能仅凭外部常识把原话改成“看起来正确”的数字。
- 可保留或添加已确认的书名号《》与引用号“”，不得借此重写说话人观点或补充事实。

正式展示层是独立文本层：原始 ASR 保真稿必须保留，不得被展示改写覆盖。

## 本步骤不做

- 不断行
- 不去标点
- 默认 ASR 保真模式下，不改大小写、不加空格调整；正式成片字幕模式仅可按上节做已确认术语大小写和千位分组。
